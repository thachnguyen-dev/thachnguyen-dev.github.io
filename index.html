Z-Force: The Laboratory

Top-down zombie shooter with a mission campaign, an endless mode and online co-op.

  • Live on Google Play
  • Unity 6 · URP

  • Mobile performance: map meshes merged per chunk, hidden faces culled, grid-based sight and collision queries.

Smiley II

A relaxing one-finger physics platformer. Drag, let go, climb.

  • Live on Google Play
  • Unity 6 · 2D physics
  • ~24k lines C#
  • 403 tests
  • com.thachnguyen.smiley
  • Physics does the playing. Each launch is one impulse on a Rigidbody2D, with a trajectory guide while aiming.
  • A soft body that is physical. The collider deforms on impact, and friction and bounce change with the shape; the idle wobble stays visual only.
  • Event-based saves on landing, platform changes and app backgrounding, so the climb survives an app kill.
  • Android back-gesture fix through a native gesture-exclusion call, after measuring which edge swipe was closing the game.
  • Rules in plain C#, separate from MonoBehaviours, and tested directly: 251 edit-mode and 152 play-mode tests.

AnimGen: one character image in, Unity sprite sheets out

Character animation was the slowest part of making games alone. AI tools that redraw every frame change the face, armour and colours between frames, and their result arrives all at once. AnimGen does the opposite: it cuts the original art into layered body parts, rigs them to an 18-point skeleton and poses them like a puppet, so every frame keeps the original pixels. The user checks and corrects the result after every step.

Stack
C# / WPF (.NET 9) app, Python backend over a token-protected local API
Models
DWPose, SAM 2, BiRefNet, SDXL + ControlNet, all offline on an 8 GB laptop GPU
Tests
148 (pytest)
